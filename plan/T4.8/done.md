Outcome: `aulo-server::SessionApi` serves `SessionService.Converse` on `aulo-agent`, and `aulod` mounts it next to `ChatService` and the grant service on the one `aulo.db` connection (`mount_database` now takes the config).

- One live `Session` per chat, built on the first Attach from `Store::chat_history`; every attached client gets every event through a broadcast channel, and a client that falls behind it is closed with `RESOURCE_EXHAUSTED` instead of being buffered without bound.
- Model: the chat's stored `provider/model`, else `providers.tiers.main`. `SwitchModel` is validated like `CreateChat`, must name a configured endpoint, is stored with `set_chat_model`, and applies from the next turn's first step (a shared `Route` read by the session's provider and context).
- Policy: one `PolicyGate` per chat over the compiled `[policy]` rules, with `approval_timeout_secs` as the session's approval timeout; an invalid rule refuses to serve (`ServerError::Policy`). Standing grants stay empty until T5.3 defines their mapping. Tools: the T4.7 registry, empty until backends land, so a call fails closed.
- Persistence: a migration adds the nullable `messages.wire` column (the `llm_wire::Message` JSON). `Store::append_turn` writes a turn's messages and their tool calls (full arguments, output, `succeeded`/`failed`/`cancelled`) in one transaction before `TurnFinished` reaches clients; a trailing tool use without results waits for them. One usage row per provider call, attributed to the endpoint and model the turn used. `content` keeps only the readable text, so `ListMessages` and search are unchanged.
- `Interrupt{all}` interrupts every live chat (scopes remain T13.3); `TakeoverDone` answers with a notice until T5.11. Bad per-request input gets a notice for that client only; a request before Attach, a second Attach or an empty request fails the stream.
- Testkit: `TestDaemonBuilder::endpoint` mounts the real session on scripted endpoints, and `TestDaemon::restart` serves again on the same home.

Not done here: evicting idle live chats and store-backed standing grants (both in `ideas.md`); a turn cut short by the daemon stopping is not stored.

Checked: `crates/aulo-testkit/tests/converse.rs` runs a tool turn, restarts the daemon, continues the chat and asserts the provider received the full history (user text, tool use, its result, the answer, the new turn), that `ListMessages` serves six rows with the tool call attached, and that three usage rows exist; a second test covers a chat with no model, a switch to an unknown endpoint and a switch that applies. Unit tests cover the history mapping, the route and the event mapping; store tests cover `append_turn`/`chat_history` and the reverted migration count. `cargo test --workspace`, `cargo clippy --workspace --all-targets -D warnings` and `cargo fmt --check` pass. No proto changed.
